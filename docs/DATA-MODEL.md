# CrimeLens — Data Model

**Source of truth:** the ordered `.sql` files in `migrations/`, applied by the
custom runner in `src/db/migrate.ts`. There is no ORM and no schema DSL —
the SQL is the schema.

---

## Tables at a glance

```
users ─────────────────────────────────────────────── PRIMARY ENTITIES
  id (PK)
  email (citext, UNIQUE)
  first_name, last_name
  avatar_svg                  ← cached DiceBear SVG ('' = none)
  contact_whatsapp, contact_telegram, contact_facebook, contact_phone
  pending_email (citext)      ← set during an email-change flow
  created_at

sessions ─────────────────────────────────────────── AUTH SESSIONS
  id (PK, also the cookie value)
  user_id (FK → users.id CASCADE DELETE)
  expires_at
  created_at

email_otps ───────────────────────────────────────── PASSWORDLESS SIGN-IN
  id (PK)
  email (citext)
  code_hash                   ← bcrypt hash of the 6-digit code
  expires_at                  ← now() + 15 min
  consumed_at                 ← set once verified or locked
  attempts                    ← failed guesses; locks at 5
  created_at

incidents ────────────────────────────────────────── CRIME PINS (GiST)
  id (PK)
  crime_type   CHECK in (pickpocketing, bicycle_stolen, street_fight, robbery, street_scams)
  occurred_at
  location     geometry(Point, 4326)  ← PostGIS, GiST indexed
  city
  description
  source       CHECK in (SEEDED, USER_REPORTED)
  created_by   (FK → users.id, NULL for seeded rows)
  created_at
```

## Column details

### `users`

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | UUIDv7 — lexicographically sortable, generated by `lib/ids.ts` |
| `email` | `citext` | Case-insensitive via the `citext` extension. UNIQUE. |
| `first_name` | `text` | Derived from the email local-part on first sign-in; editable in profile |
| `last_name` | `text` | Empty by default; editable in profile |
| `avatar_svg` | `text` | Cached DiceBear `lorelei` SVG; `''` means "no avatar", served at `/api/avatar/:id` |
| `contact_whatsapp` / `contact_telegram` / `contact_facebook` / `contact_phone` | `text` | Optional public contact handles shown on the profile |
| `pending_email` | `citext` | Holds the requested new address during an email-change until the OTP is confirmed |
| `created_at` | `timestamptz` | Server time at insert |

> `display_name` (nullable `text`) also still exists from the initial schema but
> is unused — the app derives the display name from `first_name`/`last_name`.

### `sessions`

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | UUIDv7. Signed and stored in the cookie |
| `user_id` | `uuid` | FK → `users.id ON DELETE CASCADE` |
| `expires_at` | `timestamptz` | `now() + 30 days` at creation |
| `created_at` | `timestamptz` | |

Cookie format: `session=<id>.<hmac-sha256-hex>; HttpOnly; SameSite=Lax; Max-Age=2592000`

### `email_otps`

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | UUIDv7 |
| `email` | `citext` | Address the code was sent to (not FK'd — sign-in can precede the account) |
| `code_hash` | `text` | `Bun.password.hash(code, { algorithm: 'bcrypt', cost: 10 })` |
| `expires_at` | `timestamptz` | `now() + 15 minutes` |
| `consumed_at` | `timestamptz` | Set when the code is verified, or when locked after too many attempts |
| `attempts` | `integer` | Failed verification count; the code locks at 5 (migration 0007) |
| `created_at` | `timestamptz` | Also used for the 60-second send rate-limit |

### `incidents`

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | UUIDv7 |
| `crime_type` | `text` | One of: `pickpocketing`, `bicycle_stolen`, `street_fight`, `robbery`, `street_scams` |
| `occurred_at` | `timestamptz` | When the incident happened (user-supplied or seeded) |
| `location` | `geometry(Point, 4326)` | WGS84 lon/lat point. `ST_MakePoint(lng, lat)` |
| `city` | `text` | Photon-derived for user reports; pre-seeded for seeded rows |
| `description` | `text` | Free text, max 1000 chars from UI |
| `source` | `text` | `SEEDED` or `USER_REPORTED` |
| `created_by` | `uuid` | FK → `users.id`; NULL for seeded rows |
| `created_at` | `timestamptz` | |

## Indexes

```sql
-- incidents (geospatial — the performance-critical one)
CREATE INDEX idx_incidents_location    ON incidents USING GIST (location);
CREATE INDEX idx_incidents_occurred_at ON incidents (occurred_at DESC);
CREATE INDEX idx_incidents_crime_type  ON incidents (crime_type);

-- email_otps
CREATE INDEX idx_email_otps_email      ON email_otps (email);
```

The GiST index on `incidents.location` is what makes the viewport query fast.
`ST_MakeEnvelope + ST_Intersects` against a GiST index is O(log N) instead of a
full table scan.

## PostGIS setup

The `0000_init.sql` migration runs:

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS citext;
```

Extensions live in the migration (not application code) because they require
elevated privileges and must exist before any geometry column is created.

## Migrations

Applied in filename order by `src/db/migrate.ts`; each applied file is recorded
in the `_migrations` table so it never re-runs.

| File | What it does |
|---|---|
| `0000_init.sql` | Extensions + initial tables (`users`, `sessions`, `incidents`, plus the since-dropped `magic_links` and `lost_items`) and indexes |
| `0001_password_auth.sql` | Adds `first_name`/`last_name`/`password_hash`; drops `magic_links` |
| `0002_user_avatar.sql` | Adds `users.avatar_svg` |
| `0003_crime_types_and_profiles.sql` | Renames crime types to the current set; adds profile/contact columns + `pending_email` |
| `0004_lf_contacts_images.sql` | (Lost & Found) contact + image columns — superseded by 0006 |
| `0005_otp_auth.sql` | Creates `email_otps`; OTP replaces password auth |
| `0006_drop_lost_items.sql` | Drops the `lost_items` table (feature removed) |
| `0007_otp_attempts.sql` | Adds `email_otps.attempts` for brute-force lockout |
| `0008_drop_dead_user_columns.sql` | Drops the now-unused `password_hash` and `email_verified` |

Run with: `bun run db:migrate`
